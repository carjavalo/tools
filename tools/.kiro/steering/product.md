# Product Overview

This is a document processing web application that provides various PDF and document manipulation tools. The application offers features like:

- PDF operations: merge, split, compress, crop, rotate, sort, protect, watermark, sign
- Document conversion: Word/Excel/PowerPoint to PDF, PDF to images, images to PDF/Word
- OCR text extraction from images and PDFs
- QR code generation
- Page numbering for PDFs
- Resume/document builder tools

The application is built as a full-stack web app with user authentication, allowing users to access various document processing tools through a modern web interface.
